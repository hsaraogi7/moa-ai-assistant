# Memory

This is your AI assistant's persistent memory across sessions.

## How it works

- When you tell your AI "remember that I always want X," it saves a memory file in this folder
- This `MEMORY.md` is the index - it's loaded every session so your AI can recall key facts
- Sub-files (e.g. `user_preferences.md`, `project_launch.md`) load when relevant
