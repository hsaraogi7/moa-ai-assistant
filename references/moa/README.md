# MOA Knowledge Base (6FA x BM)

This folder is the method layer for the MOA AI Assistant. Everything here comes from Sahil Sehgal's Micro Offer Accelerator (MOA 2.0) material: the 13-session slide deck, his resource docs (Micro-Offer Generator, 15-Minute MVP Funnel, SPK Method, Revenue Blueprint Calculator), his live Q&A and funnel reviews, and the MOA Action Hub step prompts. Sahil has approved its use.

## Ground rules for the assistant
- Answer from these files FIRST. If something is not covered, say "This isn't covered in the MOA material" and give general advice only if clearly labelled as general, not Sahil's method.
- When sources disagree, the slides win. Each file already resolves the known conflicts.
- Never invent numbers, testimonials, case studies or income claims for a member. Use the member's own facts, or leave a clear placeholder like [YOUR REAL RESULT].
- Never use Sahil's personal results, revenue or client stories in member copy.
- Results depend on the member's effort and market. No guarantees.
- No em dashes or en dashes in any output. Use hyphens, commas or colons.

## Files
- 00-moa-overview.md: the program, the offer ladder, core principles, glossary
- offer.md: micro offer rules, pricing, naming, pain vs desire, scorecard
- sales-page.md: MVP page, headlines, buttons, mockups, thank-you page, VSL rules, scorecard
- emails.md: purchase confirmation / delivery and abandoned cart (Sahil's material is thin here, read the warning at the top)
- ads.md: SPK, angles, image ad rules, testing, scorecard
- order-value.md: bumps, upsells, downsells, AOV stack
- numbers.md: metrics, benchmarks, budget formulas, diagnosis tree
- voice.md: how Sahil talks and reviews, tone for coaching members
